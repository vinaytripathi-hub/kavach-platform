# Security Policy — Kavach Platform

## Supported versions

Kavach Platform is in active pre-release development. There are no
publicly supported versions yet. This policy will be updated as
releases stabilize.

## Reporting a vulnerability

Email: **vinay@aurviaglobal.com**

Include:
- Description of the vulnerability and potential impact.
- Steps to reproduce.
- Your name and contact (optional, for acknowledgment).

PGP key for encrypted reports:
- Fingerprint: `6CCE4C0CF8685C7F54F16ACFA436F76F7A323EE4`
- Available at: https://github.com/vinaytripathi-hub.gpg

We aim to:
- Acknowledge receipt within 72 hours.
- Provide an initial assessment within 7 days.
- Coordinate disclosure timing collaboratively if you are an external
  security researcher.

**Do not open GitHub issues for vulnerabilities.** This is a private
repository, but its existence is not confidential and issues are
visible to all collaborators.

## Out of scope

Security issues in **dependencies** should be reported to their
respective maintainers, including Pramana Protocol:
- https://github.com/vinaysflow/pramana-protocol/blob/main/SECURITY.md
